# Security Policy

## Supported Versions

The following versions of FORTIVEX currently receive security updates:

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability within FORTIVEX, please report it responsibly:

1. **Email**: Send vulnerability reports directly to `logdivyansh@gmail.com`.
2. **Details**: Please include a clear description of the vulnerability, reproduction steps, and any proof-of-concept scripts.
3. **Response Time**: We acknowledge receipt of all reports within 48 hours and provide regular progress updates toward a resolution.

Please do not disclose security issues publicly until a patch has been released.
